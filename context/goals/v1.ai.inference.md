## Decisions

- plan: docinfer sits in the templates' layer of the coordinator's `order`, the lowest above docproc and go-ai; joins `exclusive` after wave C.
- plan: acceptance reruns over v1.ai.processing's accepted ~/docs run, which completes 2026-11-19; no wait recorded.
- plan: docproc v0.4.0 already has everything docinfer reads and has made its removals, so the goal needs no docproc change.
- design: library review round accepted L1–L5, L7–L13, L15, L17, L21–L27 and W1–W3 as the evaluation resolves them; L4 to docinfer, L15 to library and acceptance, the rest to library.
- design: go-ai exports aitest, a fake OpenAI-compatible endpoint that docinfer's library and command tests use: a route function per route over the decoded request and its arrival number, typed replies in Chat Completions only, raw replies on any route, 404 for an unscripted route, error replies with Retry-After, and a Gate with stream holds; internal/aitest stays go-ai's format-test kit — rejected docinfer's own internal endpointtest (revises W2; C22).
- design: cmd/docinfer's report is per run, one page per input content, runs/<run>/report/index.html and <sha256>.html (docproc's file name), so the cross link is one relative path; schema "2" records each input's SHA-256.
- design: the report renders everything whole: the 1,000-rune cut goes; each source shown once as its chunks in order (index, span, a rejected chunk's error, no vector).
- design: the report shows an img beside each vision text at docproc's rundir.ContentPath and links to docproc's page; the run records the relative path to docproc's directory once; the file-URL branch goes (C17).
- design: each run's inferences (vision and transcription) are a per-run file appended per batch, beside the chunk record; the manifest stays small (C15).
- design: cmd/docinfer ships a per-endpoint transport ResponseHeaderTimeout (sized by vision's observed 38.9 s) and StreamIdleTimeout for extraction's stream; the library adds no deadline (C9, L12).
- design: "latest run" is docproc's Dir.Latest, the latest that ended; --run names any other (C4).
- design: command review round accepted C1–C24 as the evaluation resolves them, all to the docinfer task.
- design: Inference gains Reason (why an image or extraction is incomplete, refused, or failed), and cmd/docinfer's Failure goes: inferences.jsonl holds each refused or failed image and window by part ID and content SHA-256 (C15).
- library: the live tier runs extraction on the agent role, every scenario also needs AI_EMBEDDING_*, and every scenario runs Chat Completions, reading no AI_<ROLE>_PROFILE; it was verified against aitest only, since no AI_*_BASE_URL was set.
