## Task brief · acceptance

**Problem**

docinfer has never run against the live rows. The embedding row serves multilingual-e5-large,
which expects a `query: `/`passage: ` convention and refuses any input over 512 tokens with a 400.
docinfer sends no prefix, splits by runes (2,000-rune chunks overflow most non-Latin scripts), and
keys its caches on the alias rather than the served model. The goal closes here, so every finding
is fixed in this task, leaving capstone.data-intelligence a docinfer with no deferred defects.

**Behaviors**

go-ai
1. An embedding request carries an input type, `ai.InputType` (query or document). A Client's
   embedding profile (`ai.Options.Embedding`, an `EmbeddingProfile` read as strict JSON, no
   presets) maps each declared type to a text prefix or a native member. An undeclared type is
   sent bare; a native member clashing with the typed fields is refused before sending.
   `(*Client).EmbeddingProfile()` returns the profile.
2. `(*Client).Tokenize` counts a text's tokens over the engine's tokenize route; the count equals
   the prompt tokens the embedding of that text reports.
3. `aitest` answers the tokenize route and records an embedding's input as sent, prefix included.
4. `infer embed --input-type` sends the type under a profile setting; `infer tokenize` prints the
   count.
5. go-ai's live tier, with input-type and tokenize scenarios, passes against the rows on the
   release candidate.

docinfer base
6. Embeddings send "document". The embedding identity keys on the document convention the client
   reports; `Profile` reports the query convention.
7. All four capabilities' identities and `Profile` name the served model the host resolves.
8. Vision and extraction take `Native` sampling, hashed into their identities.
9. `chunk.Splitter` measures through a host-supplied token counter: bound in tokens, no overlap,
   every chunk within the bound, spans still covering the text. `chunk.Version` is 2.
10. Each text's chunk spans are held in the Cache under the chunker identity (version, bound,
    the tokenizer's served model) and the source text's digest, so a rerun sends no tokenize
    request. `docinfertest`'s suite covers it; the file, memory, and PostgreSQL caches pass it.

cmd/docinfer
11. The served model comes from each listing's `root`, else config `served_model`; a mismatch
    between them stops the run before any inference.
12. `embeddings.input_types` is required, with no starting value; `embeddings.tokenizer` names
    the tokenize endpoint; `chunk_size` is in tokens, starting at 480; each capability takes
    `native`; nothing sets `truncate_prompt_tokens`.

Acceptance (rows direct; the architect is told before the sweep and before the timed run, so
ai-hosting is paused)
13. Vision concurrency sweep: 320 seeded images at each of 4..16; best is the most images a minute
    with no failures, a value within 3% of it giving way to the lower. The winner sets the
    acceptance config only; cmd's starting value stays 4. Audio runs at 8, embedding at 4.
14. The timed run reads `~/runs/docproc/final` (run `01a208e5-e581-7b95-b43a-0f91f8d3b40e`),
    never writing it, as a detached `systemd-run --user` unit, and passes: exit 0; every refused
    or failed item classified; 1,024-dimension unit-norm vectors; the report renders; covered
    runes traced against the spike's 41,299,926, images 3,471 against 3,470, windows 1,208
    against 1,254; time recorded, not gated.
15. A rerun sends no inference or tokenize request (the model listing aside) and writes
    identical chunk lines.
16. The base live tier, extraction on the agent row included, and cmd's `TestCLI_RunAndReport`
    pass on the rows with dummy `AI_<ROLE>_TOKEN`s, so the gateway key is never sent.
17. Every finding is fixed here; a final rerun after the fixes meets 14 and 15.
18. The evidence is in docinfer's acceptance doc; raw results stay at `~/runs/docinfer/acceptance`,
    out of git.
19. For sync the goal record carries: add docinfer to capstone.data-intelligence's repos;
    data-intelligence.md's edits re-anchored, and a line that the gateway serves the embedding
    tokenizer at `/embedding/v1/tokenize` (so through the gateway `embeddings.tokenizer` names the
    embeddings endpoint; direct to the row it names the row's root); the ~263 gate, go-elemental README, and `[tasks.docinfer]` edits dropped as
    moot; the docproc-backlog `rundir.ReportPage` item kept. Sync proposes staging
    docproc-coverage.
