## Task brief · v1.ai.inference · library
Problem       docinfer has scaffolding and no code. Its design note
              settles the base module's API, but nothing in it is built,
              and job, postgres and cmd/docinfer each require it. The
              spike's inference at 6a631f1 is one process running
              whole-record phases over in-memory maps, written against
              spike-ai-pipeline-client and the spike's own command
              packages. Only its chunker, and processing v0.9.0's join,
              are plain standard library. The pipeline Cerebro needs
              does not exist yet. It must be cached and joined across
              jobs, bounded per capability, streamed in batches as made,
              mapped row by row onto go-ai's failures, and able to
              extract by a caller's schema. go-ai v0.4.0 is released, so
              nothing blocks it.
Behaviors     chunk
              1. Splitter{Bound}.Split cuts text along headings, then
                 paragraphs, then sentences, then a hard cut. Each chunk
                 is at most Bound runes. Each chunk carries its Span
                 [Start, End) in bytes, in text order. Together the
                 chunks cover the text except trimmed white space, and
                 an empty text yields none. A Bound below 1 matches
                 chunk.ErrRequest. Settings gives Version and Bound.
                 chunk.Version is "1".
              2. A committed golden corpus of chunks, named for
                 chunk.Version, pins the splitting. A changed cut fails
                 it with "change the version".
              join
              3. join.Join merges window transcripts in plan order. A
                 refused or missing window is "". Each seam's bound is
                 its span's seconds times Request.WordsPerSecond,
                 rounded up, and at least 2. A WordsPerSecond below 1
                 matches join.ErrRequest. There is no default and no
                 build tag. Seam encodes with JSON tags, and
                 Transcript.Text joins its words. TestJoin's table and
                 the settled-prefix tests move from processing and pass.
              The cache and its key
              4. Key(id, content) is "<capability>/" followed by the
                 lowercase hex SHA-256 of these parts, each
                 length-prefixed: Version, then the identity's
                 capability, model and settings, then content. A golden
                 key per capability pins the form, and a changed key
                 fails with "change the version".
              5. A Cache's Get answers many keys in one call, each in
                 order, nil for a miss. Put replaces. Values come back
                 whole. docinfertest.Cache runs that contract against a
                 new, empty cache made for each case. It imports only
                 the root and the standard library.
              6. FileCache holds <dir>/<capability>/<xx>/<hash>.json, and
                 NewFileCache refuses "". MemoryCache holds the same
                 values in memory. Both pass docinfertest.Cache and are
                 safe for concurrent use under -race.
              7. A held value that doesn't decode as Held is a miss: the
                 model is asked again, and its Put replaces the value. A
                 held or new vector whose length isn't Config.Dimensions
                 is a permanent error, and that check runs before Put
                 and again after Get.
              Construction
              8. New panics, naming the field, on a nil Cache, Bounds or
                 Embeddings.Client, or on a set Vision, Transcription or
                 Extraction whose Client is nil. It refuses a value below
                 1 with ErrRequest: Chunker.Bound, Dimensions, Pending,
                 EmbedBatch, BatchBytes, Join.WordsPerSecond, and each
                 MaxTokens. It also refuses an empty Model. NewBounds
                 refuses any of its four bounds below 1 with ErrRequest.
                 Nothing has a default.
              9. Each capability's Identity holds its settings in one
                 JSON encoding with fixed member order, led by "request",
                 the request's version:
                 - vision: prompt, max_tokens, effort
                 - transcription: mode, read from the client's
                   TranscriptionMode() as "route" or "chat", then prompt
                   and language
                 - extraction: name, prompt_sha256, schema_sha256,
                   max_tokens, effort
                 - embeddings: settings ""
                 Profile reports every identity, Dimensions, and the
                 Splitter's Settings.
              Bounds and the join of work in flight
              10. A Bounds caps each capability's requests in flight
                  across every pipeline built on it. A bound test holds
                  requests at aitest's Gate until the bound is reached.
                  It asserts the bound is reached and never passed, with
                  no sleep.
              11. The claim table answers each key once across
                  concurrent jobs, single keys and embedding batches
                  alike. A waiter gets the leader's result and counts it
                  Held. A waiter holds no Bounds slot. A waiter whose
                  leader ends without a result asks the model itself. A
                  cancelled waiter returns at once. A refusal or a
                  permanent error is shared. These -race tests prove it:
                  the leader is cancelled, the leader fails transiently,
                  a waiter is cancelled, the leader panics (no waiter is
                  stranded), and a batch is partly in flight.
              Run
              12. Run streams per job, as things are made: each
                  Inference, each extraction's Progress, each Batch once
                  its embeddings complete, and Counts last. yield is
                  called from Run's goroutine alone. Run waits for its
                  requests in flight before it returns. A result is held
                  before anything derived from it is yielded. A
                  cancelled context yields ctx.Err() alone, last.
              13. Run pulls an input only while fewer than Pending of
                  the job's inputs are admitted and unfinished. A batch
                  is yielded when the next chunk would take its
                  marshalled JSON past BatchBytes, or when no embedded
                  chunk is waiting. A chunk that alone passes the cap is
                  a batch of one. A Batch holds each part and source
                  once, by index. Digest is derived from the chunks.
              14. Text and Markdown outputs are chunked as source kind
                  output, and a Metadata input as kind metadata.
                  MetadataText builds that text from the depth-0 part.
                  Each embedding is keyed by model and chunk digest
                  alone, with EmbedBatch texts per call and the vector
                  as base64 that DecodeVector reads. Content is opened
                  only on a miss or to chunk text. A content miss yields
                  *MissingError, which wraps Content.Open's
                  fs.ErrNotExist.
              15. An image is described from its content as a data URL
                  of Output.MediaType, then chunked as kind vision. An
                  image without a MediaType is a permanent error. A
                  reply that completes with only a refusal part is
                  outcome refused, held, with the refusal's text in
                  Held.Refused and Inference.Reason. An incomplete reply
                  keeps its text, is held, and records its reason.
              16. A window is transcribed with Open calling Content.Open
                  per attempt. FileName is .wav for audio/wav and .mp3
                  for audio/mpeg; any other type is a permanent error.
                  Windows group by {Part.ID, Event.Stage} and are placed
                  by MetaWindow, the first event of an index winning. A
                  group ends at the first of these:
                  - the window count of its audio plan record
                  - its last window, once every earlier index is in
                  - the end of Run's inputs
                  A video plan record ends no group. The group joins at
                  seams taken from MetaSeamAfter or MetaSeamBefore, then
                  is chunked as kind transcript. A window that is
                  refused, failed, incomplete, or never cut joins as
                  empty and is listed in Failed. The transcript's
                  outcome follows design.md's rule.
              17. Extraction runs Options.Extract once over each source
                  text except metadata. The request is GenerateStream
                  with a strict JSONSchemaFormat, folded by an
                  Accumulator. Progress is coalesced to at most one a
                  second per source text, each carrying the text since
                  the last. Outcomes:
                  - completed: extracted, its OutputText
                  - incomplete: partial text kept and held
                  - refusal only: refused, held
                  - broken part way: nothing held, takes the transport
                    row; the progress already yielded stands
                  An Extract with an empty or invalid name, prompt or
                  schema is refused with ErrRequest before any input is
                  read. A run that asks for extraction with no
                  Config.Extraction fails as permanent. Every case is
                  tested against aitest.
              18. go-ai failures map row by row as design.md's table
                  states, one aitest test per row:
                  - refused: 400, 413, 415, 422. An embedding batch is
                    split a text at a time only on a refused status.
                  - permanent: 401, 403, 404, 501, 505, any other 4xx
                    except 408 and 429, and UnsupportedError
                  - transient: 408, 429, and any 5xx except 500, 501
                    and 505, with RetryAfter carried. A transport
                    failure or broken stream is transient too.
                  - 500 / failed / undecodable: stops the job, except
                    that on Options.Final the item is recorded failed,
                    never held, and the job goes on
                  - IncompleteTranscriptError: the window incomplete,
                    held
                  Permanent reports exactly the permanent rows and
                  design.md's listed input defects.
              19. Counts counts occurrences per design.md's shapes, each
                  capability's counts nil when that capability is
                  skipped or not asked for. TranscriptionCounts has
                  Incomplete. Tokens are this job's requests only.
                  Embedded plus Rejected equals the chunks in the job's
                  batches.
              Live tier, CI, release, docs
              20. An integration-tagged tier drives vision,
                  transcription (route and chat), embeddings and
                  extraction against live endpoints, read from go-ai's
                  AI_<ROLE>_BASE_URL, _TOKEN, _HEADER and _MODEL
                  variables. A scenario whose variable is unset skips,
                  naming the variable. mise run integration runs the
                  tier verbose, and CI never does. The check vets, fixes
                  and lints the tier under the integration tag.
              21. The check runs the base module with GOWORK=off.
                  depguard holds every file to the standard library,
                  docproc and go-ai. A committed go.work lists the base
                  module. mise has an upgrade task. CI runs the check. A
                  pushed tag v* or <module>/v* publishes a GitHub release
                  from that module's CHANGELOG section.
              22. Every package's doc.go inventories its exported names.
                  The root's doc states the consumer's contract (drop a
                  quarantined or failed part's results by that part's
                  own event) and names the host as the owner of a

                  - cites spike-ai-pipeline 6a631f1 for chunk and

Test seams    - docinfer.New and Pipeline.Run, driven through go-ai's

## Decisions

- plan: tasks design → library → job → postgres → docinfer → acceptance, one session each; job split from library, which alone is docproc's library task's size.
- plan: fresh `init`, scaffolding only; library's first slice copies spike-ai-pipeline's docinfer at 6a631f1 in one commit, as go-ai and docproc did — rejected seeding init with the spike, so the design review precedes any code.
- plan: public under Apache-2.0, as go-ai and docproc.
- plan: each module (base, postgres, cmd/docinfer) starts at v0.1.0 on its own tags, the base tagged first; design assigns only the task that releases each tag.
- plan: docinfer sits in the templates' layer of the coordinator's `order`, the lowest above docproc and go-ai; joins `exclusive` after wave C.
- plan: docinfer's design note takes over docproc's layers.md docinfer sections; they retire at this goal's sync, not v1.ai.processing's.
- plan: acceptance reruns over v1.ai.processing's accepted ~/docs run, which completes 2026-11-19; no wait recorded.
- plan: docproc v0.3.0 already has everything docinfer reads and has made its removals, so the goal needs no docproc change.
- design: join of work in flight is docinfer's own claim table (claim(keys), one mechanism for single keys and batches; -race tests for leader cancelled, leader transient failure, waiter cancelled, leader panic, batch partly in flight) — rejected golang.org/x/sync/singleflight: it meets the waiter rule only through DoChan, a leader flag, the waiter's own ctx check and a retry loop, and Embed answers a batch of keys, so embeddings would need a second mechanism; the base module stays docproc + go-ai.
- design: a nested audio part's end of windows comes from docproc's plan record output (MediaAudioPlan, MediaVideoPlan), admitted as an input for its count; no window carries MetaCount (L19).
- design: no library defaults, as docproc: New and NewBounds refuse a value below 1 with ErrRequest; cmd/docinfer ships the operator's starting values (L24; settles layers.md's 512 KiB BatchBytes).
- design: a quarantined or failed part's outputs reach the model before the part's own event; the root's doc states consumers drop by that event, rather than job holding outputs (L6).
- design: Version joins Key's hash, and a held value that doesn't decode is a miss the next Put replaces; Cache keeps Get and Put (L18).
- design: an embedding is keyed by model and the chunk's SHA-256 alone, settings ""; the chunker stays in Profile (L16).
- design: the seam bound is derived per seam from MetaSeamBefore/After at Config.Join's words per second, no default (L20).
- design: library review round accepted L1–L5, L7–L13, L15, L17, L21–L27 and W1–W3 as the evaluation resolves them; L4 to docinfer, L15 to library and acceptance, the rest to library.
- design: go-ai exports a response's output text (a (*protocol.Response).OutputText method), and go-ai's transcribe.go, tools/infer and quick-start use it; docinfer keeps no helper (L14) — root fix in go-ai, per the architect: fix problems at their root, go-ai isn't blocked.
- design: go-ai exposes the client's transcription mode ((*Client).TranscriptionMode()), and docinfer's Identity reads it from the client — rejected a host-restated docinfer.Transcription field, which can disagree with the client and silently mis-key the cache (revises L13).
- design: go-ai exports aitest, a fake OpenAI-compatible endpoint that docinfer's library and command tests use: a route function per route over the decoded request and its arrival number, typed replies in Chat Completions only, raw replies on any route, 404 for an unscripted route, error replies with Retry-After, and a Gate with stream holds; internal/aitest stays go-ai's format-test kit — rejected docinfer's own internal endpointtest (revises W2; C22).
- design: a new task, go-ai, runs between design and library and releases go-ai v0.4.0 (OutputText, TranscriptionMode accessor, aitest), tagged before docinfer's v0.1.0 — rejected go-ai slices inside library, already the goal's largest task.
- design: cmd/docinfer's report is per run, one page per input content, runs/<run>/report/index.html and <sha256>.html (docproc's file name), so the cross link is one relative path; schema "2" records each input's SHA-256.
- design: the report renders everything whole: the 1,000-rune cut goes; each source shown once as its chunks in order (index, span, a rejected chunk's error, no vector).
- design: the report shows an img beside each vision text at docproc's rundir.ContentPath and links to docproc's page; the run records the relative path to docproc's directory once; the file-URL branch goes (C17).
- design: each run's inferences (vision and transcription) are a per-run file appended per batch, beside the chunk record; the manifest stays small (C15).
- design: cmd/docinfer ships a per-endpoint transport ResponseHeaderTimeout (sized by vision's observed 38.9 s) and StreamIdleTimeout for extraction's stream; the library adds no deadline (C9, L12).
- design: "latest run" is docproc's Dir.Latest, the latest that ended; --run names any other (C4).
- design: command review round accepted C1–C24 as the evaluation resolves them, all to the docinfer task.
- design: a part's window group ends at whichever comes first: the window count of its audio plan record (MediaAudioPlan), the last window (no MetaSeamAfter) once every earlier index is in, or the end of Run's inputs — docproc v0.3.0's video plan record precedes its windows and holds no count, so it ends none (corrects the L19 line above, which named MediaVideoPlan).
- design: Inference gains Reason (why an image or extraction is incomplete, refused, or failed), and cmd/docinfer's Failure goes: inferences.jsonl holds each refused or failed image and window by part ID and content SHA-256 (C15).
- design: an incomplete transcription window joins as empty and is listed in the transcript's Failed; TranscriptionCounts gains Incomplete (L9).
- design: docinfer.New and job.New each take a Config struct, as dispatch.New does, since each needs more than four required inputs; NewBounds takes its four bounds positionally and returns (*Bounds, error) (construction-and-execution).
- design: STANDARDS.md keeps its timeouts.md pointer as one owner per bound, the host's transport owning a model request's time, and adds a service-tiers.md pointer for Cache and its implementations.
- design: G3 adds a public aitest (route functions over the decoded request and its arrival number, typed replies in Chat Completions only, raw replies on any route, 404 for an unscripted route, error replies with Retry-After, a Gate with stream holds) rather than exporting internal/aitest, which stays go-ai's format-test kit.
