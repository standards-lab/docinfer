Problem       docinfer v0.2.0 ships the Cache interface, FileCache,
              MemoryCache and docinfertest, but no cache a host can share
              across replicas. Cerebro keeps the cache in PostgreSQL
              beside docproc's index. design.md settles docinfer/postgres
              as a provider module over sqlate with one row per key, a
              batch's Get in one query, and migrations the host applies,
              as docproc/postgres ships its own. The module isn't built,
              and docinfer has no PostgreSQL harness, no tier that runs
              against one, and no CI job for it. Its `mise run
              integration` name is already taken by the base module's AI
              live tier. postgres has no spike source, so all of it is new
              code. docinfer is current, and so are sqlate's tags.
Behaviors     The module
              1. github.com/standards-lab/docinfer/postgres is a nested
                 module on go 1.27.4. It requires docinfer v0.2.0, sqlate
                 v0.7.0, sqlate/postgres v0.8.0 and pgx v5.13.0, and holds
                 sqlint v0.4.0 as a tool. No replace directive. It imports
                 nothing else beyond the standard library, and nothing in
                 the base module imports it.
              The schema
              2. Migrations returns a sqlate migration set named Source,
                 "docinfer", recorded in its own history table, Table,
                 "docinfer_schema_version". The set is read from
                 embedded migration files. Every object the set creates
                 is prefixed docinfer_; a test fails on an object
                 without the prefix. The host applies the set, and the
                 cache never migrates.
              3. Migration 0001 creates docinfer_cache with one row per
                 key:
                 - key: text, the primary key, holding Key's string as
                   given
                 - value: bytea, NOT NULL, under
                   CHECK (octet_length(value) > 0)
                 - written_at: timestamptz, NOT NULL, set from the
                   database's clock
                 It creates no index beyond the primary key and no
                 version column, since Version is in Key's hash. Its
                 down migration drops the table.
              4. A golden-hash test pins each released migration: its
                 name, the SHA-256 of its up and down texts, and whether
                 it is transactional. It fails on a changed migration, an
                 unlisted one, and a listed one missing from the set.
              The statements
              5. The cache's SQL is authored statement files, compiled
                 once for PostgreSQL through sqlate's query package and
                 named for their operation. Each statement is native
                 tier with a port note:
                 - the lookup uses key = ANY over a text[] parameter.
                   Port: an IN list expanded per key count.
                 - the hold uses INSERT ... ON CONFLICT (key) DO UPDATE
                   and now(). Port: MERGE retried on a unique violation,
                   with the engine's current timestamp.
                 sqlint passes over the statements and the migrations.
              6. Statements lists the compiled statements in name order,
                 and a test pins the list. Verify prepares every
                 statement against the schema a session reaches, so a
                 database without the set, or with a set behind the
                 statements, fails Verify.
              New
              7. New(ctx, *sqlate.DB) returns (*postgres.Cache, error).
                 - A nil DB panics, naming the DB.
                 - A pool not on pgx's database/sql driver is refused
                   matching docinfer.ErrRequest, naming the driver
                   connection's type it found. New reads the driver from
                   a connection it takes from the pool under ctx, so a
                   pool it can't reach fails too.
                 postgres.Cache is safe for concurrent use. Its zero
                 value is not ready.
              Get
              8. Get of n keys, n ≥ 1, runs exactly one query whatever
                 n is. It returns values[i] for keys[i], in order, nil
                 for a miss. A key asked twice is answered twice, each
                 answer its own slice.
              9. Get of no keys returns an empty result and runs no
                 query.
              Put
              10. Put runs one statement. It inserts the key's row, or
                  replaces a held value with the new one, and sets
                  written_at to the database's now() either way.
                  Concurrent Puts of one new key all succeed, and the
                  key holds one of their values whole.
              The guards
              11. Get and Put refuse a key not in Key's form,
                  "<capability>/<64 lowercase hex>" with a capability of
                  lowercase letters, matching docinfer.ErrRequest, before
                  any query. Get checks every key.
              12. Put refuses a nil or empty value, matching
                  docinfer.ErrRequest, before any query.
              13. An ended context fails Get and Put with the context's
                  error before any query, and a Put under an ended
                  context leaves its key a miss.
              The suite
              14. postgres.Cache passes docinfertest.Cache, every case,
                  in the module's integration tier. Each case gets a
                  new, empty cache over its own scratch database from
                  sqlate's pgtest with the set applied, on the server
                  DOCINFER_DSN names.
              The harness and tasks

                  PostgreSQL service:
                  - built from its own Dockerfile, FROM
                    postgres:19.0-alpine, the image's one pin
                  - user, password and database app

                    flags
                  - data on tmpfs

                    5437}

                  The test package's TestMain sets a non-UTC zone.
